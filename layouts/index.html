Architektur

Eine Architektur, die mitwächst

Ob schlanker Einstieg oder vollständig entkoppelte Cloud-Architektur – {{ .Site.Params.product }} wächst mit Ihren Anforderungen. Der produktive Kern läuft heute als Blazor-Server-Anwendung mit MudBlazor – direkt gegen PostgreSQL, mit QuestPDF für Auftrags- und Kundenstammblätter. Parallel entsteht eine entkoppelte Architektur: ein React/TypeScript-Frontend spricht über eine eigenständige .NET 8-Web-API mit der Datenbank, damit Oberfläche und Geschäftslogik unabhängig voneinander wachsen können.

  • {{ partial "icon.html" "layout-dashboard" }} Bewährter Kern für Kunden, Artikel, Aufträge und Ablage
  • {{ partial "icon.html" "git-branch" }} Modernes React 19 + Vite-Frontend, angebunden an eine eigene .NET-API
  • {{ partial "icon.html" "database" }} PostgreSQL als gemeinsame Datenbasis, per Entity Framework Core
  • {{ partial "icon.html" "shield-check" }} Anmeldung und Dateizugriff über Microsoft Entra ID und Graph
  • {{ partial "icon.html" "server" }} Containerisiert mit Docker, einsetzbar in Ihrer Infrastruktur oder in der Cloud
